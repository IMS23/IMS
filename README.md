# MIDI Composition Assistant

AI-powered MIDI composition workstation built with Python and Qwen2.

## Features

* Chord progression generation
* Harmony suggestions
* Melody generation
* Bassline generation
* Drum pattern generation
* Arpeggio generation
* MIDI export
* Save and load projects
* Audio preview
* Local AI assistant powered by Ollama and Qwen2 7B

## Tech Stack

* Python
* PySide6
* MIDIUtil
* Ollama
* Qwen2 7B
* JSON-based style and mood profiles
